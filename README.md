# Superstore Sales & Profitability Analysis

## Project Overview
This project analyzes the Sample Superstore dataset to identify sales trends, profitability patterns, and business performance across regions, product categories, and customer segments.

The goal is to transform raw sales data into meaningful business insights using Microsoft Excel 2016.

## Tools & Technologies
- Microsoft Excel 2016
- PivotTables and PivotCharts
- Excel Formulas
- Slicers and Interactive Dashboard
- Data Cleaning and Data Validation

## Dataset
- Source: [Sample Superstore Dataset – Kaggle](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)
- Records: 9,994 rows
- Data includes orders, customers, products, sales, profit, quantity, and discounts.

*Note: This is a sample dataset downloaded from Kaggle, not verified real company data.*

## Project Steps
1. Imported and explored the raw dataset.
2. Cleaned and validated the data.
3. Checked for duplicate records and missing values.
4. Created calculated columns:
   - Order Year
   - Profit Margin
   - Sales Category
5. Built PivotTables to analyze sales and profit.
6. Created PivotCharts and an interactive dashboard.
7. Added slicers to filter results by region, category, and segment.

## Key Business Insights
- The West region generated the highest sales and profit.
- Technology was the top-performing category in sales and profit.
- The Consumer segment generated the highest sales and profit.
- Phones recorded the highest sales among sub-categories.
- Copiers generated the highest profit among sub-categories.
- 2017 recorded the highest annual sales and profit.
